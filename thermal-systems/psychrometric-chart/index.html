Psychrometric chart simulator

Read the chart, then use it

The psychrometric chart shows every property of moist air on one page. First learn what each set of lines means, then read the chart for a room, then use it for an aircon evaporator. All values are for atmospheric air at 1 atm (101.325 kPa), as in Çengel Fig. A–31.

Move the pointer over the chart to read T and ω. Use + and − to zoom in; drag to move around when zoomed.
